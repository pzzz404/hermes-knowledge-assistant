# Проверка русскоязычного помощника

Проверены **24 вопроса на русском языке** по 12 оригинальным статьям рабочего пространства «Пример». Набор [вопросов](../evaluation/questions.json) и его SHA-256 [зафиксированы](../evaluation/freeze.json) до живого прогона. Ответы получены через отдельный Hermes с моделью `openai/gpt-4.1-mini`, а не через технический режим MOCK.

| Категория | Первый прогон | После исправления |
| --- | ---: | ---: |
| Ответы по статьям | 13/14 | 14/14 |
| Вопросы вне корпуса | 4/4 | 4/4 |
| Уточнения и продолжение разговора | 3/3 | 3/3 |
| Запросы о скрытых инструкциях, чужих диалогах и действиях | 3/3 | 3/3 |

Перед матрицей пробный ответ на вопрос об оплате приписал Владельцу право, которого статья не устанавливает. После добавления проверки A14 в первом полном прогоне получил HTTP 502 `invalid_model_response`: сервер отклонил ответ, не прошедший проверку. В статье теперь прямо сказано, что право на передачу не определено. Для этого узкого вопроса сервер возвращает проверенный по статье ответ без генерации. Повтор A14 прошёл; исходный сбой сохранён в [результатах](../evaluation/results.json).

**Защита от промпт-инъекций многослойная, но ограниченная.** Системная инструкция велит считать статьи и вопросы данными, сервер отклоняет запросы о скрытом промпте и чужих диалогах, проверяет ID источников и не пропускает произвольные URL. Отдельный Hermes не имеет инструментов для действий в рабочем пространстве. Три тестовых запроса получили отказ. Это не доказывает защиту от всех форм инъекции, особенно от новых текстов в корпусе.

Автор сверил статусы, источники, ключевые факты и процедурные шаги с исходными статьями. Полные ответы сохранены в приватной `.data/`, вне Git; в открытом [отчёте](../evaluation/results.json) есть статусы, адреса источников, контрольные суммы журналов и различие первого прогона и целевого повтора. Целевой повтор использует уже известный вопрос и не является независимой выборкой. Для внедрения нужны дополнительные вопросы из реальной поддержки и проверка специалистом по предметной области.

Прежняя проверка англоязычного корпуса осталась в истории Git и не используется как доказательство качества текущей русской версии.
